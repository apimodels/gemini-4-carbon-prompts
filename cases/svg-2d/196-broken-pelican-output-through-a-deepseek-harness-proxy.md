# Broken pelican output through a DeepSeek harness proxy

Gemini 4 Carbon case 196 of 223 · SVG, Drawing and 2D Animation · [简体中文](#中文)

By [@leo114119](https://x.com/leo114119) · [original post](https://x.com/leo114119/status/2120725027180179726) · 2026-11-12 · [see it in the apimodels.app gallery](https://apimodels.app/gemini-4-carbon-prompts/svg-2d)

- **What it is:** A pelican-on-a-bicycle result from Carbon on an Ultra 20x subscription, routed through a DeepSeek agent harness via a reverse proxy. The output is badly degraded, which the author offers as support for claims that proxied Gemini gets worse.
- **Media:** Image. About 697 views and 7 likes as of 12 November 2026.
- **Tool:** DeepSeek harness via reverse proxy
- **Prompt:** not published here. We do not reconstruct unpublished prompts.
- **Note:** A failure case: the harness around the model can change results a lot.
