# Six fixed one-shot prompts through a third-party API, from pelican to Breakout

Gemini 4 Carbon case 94 of 223 · Head-to-Head Tests · [简体中文](#中文)

By hype or code · [original web page page](https://hypeorcode.com/c/breakout/gemini-4-carbon/) · 2026-11-10 · [see it in the apimodels.app gallery](https://apimodels.app/gemini-4-carbon-prompts/head-to-head)

- **What it is:** hypeorcode.com, which runs daily, sends six fixed one-shot prompts (pelican, wristwatch, landing page, Breakout, logo, About copy) through a third-party API as one user message at medium effort with a 32,768 output-token limit. Carbon's runs took from 33 s to 5 min 21 s and cost from $0.020 to $0.27 each.
- **Where:** web page
- **Tool:** Third-party API
- **Numbers the author reported:** Pelican 3 min 2 s, $0.12 · Watch 5 min 21 s, $0.22 · Landing 3 min 59 s, $0.27 · Breakout 2 min 25 s, $0.19 (109 in / 19,175 out tokens, 1,622 lines) · Logo 3 min 20 s, $0.23 · About 33 s, $0.020 · 32,768 output-token limit
- **Prompt:** published by the creator, quoted in full below.
- **Note:** The prompt shown is the Breakout one. Other models' runs are on the same site, with no verdict text.
- **Also:** [hypeorcode.com/](https://hypeorcode.com/)

**Prompt (the creator's own words)**

````text
Make a Breakout game I can play right now with the keyboard or the mouse. Give it several levels, a score and some juice. It must be one complete, self-contained HTML file: inline all CSS and JavaScript, and make no network requests of any kind (no CDNs, web fonts or remote images). Reply with the file in a single `` ```html `` code block.
````
