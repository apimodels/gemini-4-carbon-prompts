# Cozy medieval diorama builder in a single 930 KB HTML file

Gemini 4 Carbon case 150 of 223 · Games · [简体中文](#中文)

By FireTable · [original GitHub page](https://github.com/FireTable/tiny-glade) · 2026-11-11 · [see it in the apimodels.app gallery](https://apimodels.app/gemini-4-carbon-prompts/games)

- **What it is:** A /swarm multi-agent run in Antigravity built a browser diorama builder with procedural stone walls, auto-carved arches and bridges, 195k-blade GPU grass and procedural WebAudio, with every asset generated in code. A making-of report is linked from the README.
- **Where:** GitHub

- **Numbers the author reported:** 1 h 41 min swarm run · 9 agents · 22,910 LOC with 0 merge conflicts · 4.14x peak parallel speedup · 4-round visual/shader QA loop · final file 929.6 KB · 195k-blade GPU grass
- **Prompt:** published by the creator, quoted in full below.
- **Note:** Clone of an existing commercial game's concept and name (Tiny Glade).
