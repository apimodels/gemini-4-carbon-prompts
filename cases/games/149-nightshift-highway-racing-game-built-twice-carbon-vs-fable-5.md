# NIGHTSHIFT highway racing game built twice: Carbon vs Fable 5.2

By Ediz Ege Mercan (GitHub EddizEge) · [original post](https://lab.edizegemercan.com/posts/nightshift-gemini-4-carbon-vs-claude-fable-5-2/) · 2026-11-11 · [see it in the apimodels.app gallery](https://apimodels.app/gemini-4-carbon-prompts/games)

- **What it is:** From one long prompt, Carbon (High) in Google Antigravity chose the stack, wrote a rainy midnight highway racing game (WebGL2, three.js, Rapier), modelled the player car in Blender with a Python script, pulled in CC0 assets and tested it in a browser, with no human-written code. Fable 5.2 built the same game in Claude Code at xhigh as a lead agent delegating to Opus 5.5 subagents.
- **Where:** blog
- **Tool:** Google Antigravity (the write-up says the Antigravity CLI)
- **Numbers the author reported:** Carbon: about 2 h 8 min · Carbon: about $10 (estimated at third-party per-token prices) · Carbon: 20 source files / 7,705 lines · Car model: 89,900 triangles · Fable: about 16 h 36 min · Fable: "$300+" ($236 logged) · Fable: 119 files / 35,831 lines
- **Compared with:** Fable 5.2. No single winner: Carbon costs far less and built a decent game, while Fable treated it as a full project with planning, parallel subagents and a self-playing test driver.
- **Prompt:** not published here. We do not reconstruct unpublished prompts.
- **Note:** Described as one long prompt, not published. Carbon's cost is the author's estimate at third-party per-token prices.
